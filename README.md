# CMPUT455_code
Python 3 code for the CMPUT 455 course at University of Alberta
Martin Mueller, 2017-2026

Much of the code has been cleaned up, refactored, and expanded 
with Gemini in 2026. Type annotations have been added and checked with mypy.

- `Go_programs` contains our series of programs `Go0`, `Go1`, ...
- `lecture_examples` has sample code used in class, and extra examples
